# Curation is structured by scarcity of occurrence, not a blended interest score

Each event gets a recurrence class (one-off, limited run, recurring) derived deterministically from page evidence. Only one-offs and limited runs are eligible for the don't-miss flag, which the model assigns with a stated why-line. Recurring events are never on the don't-miss list. The flag and why-line are re-judged only when an event's underlying facts (date, venue, status) change, never on every run. We rejected a blended "interest score" because it is opaque, unstable between runs, and reads as arbitrary on a taste-neutral public site. The model's judgment lives inside the structure (which one-offs are notable, and why), not over it.
